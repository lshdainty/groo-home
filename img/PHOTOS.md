# 사진 출처

홈페이지에 쓰는 사진은 [Unsplash](https://unsplash.com) 에서 받았다. Unsplash 라이선스(출처 표기 없이 상업적으로 쓸 수 있다)를 따른다.
이미지 주소는 `https://images.unsplash.com/photo-<id>` 이다.

| 파일 | Unsplash 사진 id |
|---|---|
| `svc-next.jpg` | `1495908333425-29a1e0918c5f` |
| `photo-*.jpg` (이전 사진) | 출처 id 미기록. 현재 페이지에서는 쓰지 않는다 |

서울 거리·카페 사진(한글 간판이 보이는 것)을 쓴다 — 서양인이 나오는 사진은 쓰지 않는다(2026-10-20 사용자 결정). 사진을 바꿀 때도 같은 기준이다.

메인의 사진 띠(`strip-1~6`)는 2026-11-16 그룹 소개 영상 반복으로 바뀌며 지웠다.
